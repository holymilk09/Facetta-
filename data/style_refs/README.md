# House style references

Images here anchor the rendering STYLE of generated jewelry images: the
style reference rides as a second input on multi-image edit engines with a
strict style-only rule — lighting, finish, presentation come from here;
design elements never do.

This starter set was bootstrapped from the strongest early renders. Replace
it with the designer's APPROVED images — the first file (name-sorted) is the
default house anchor. Curation is the designer's call; code never chooses
taste.
