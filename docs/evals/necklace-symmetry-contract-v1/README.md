# Necklace symmetry contract v1

This is a **provider-free contract fixture**, not a visual-quality result and
not release authority. It tests the deterministic half of Facetta's necklace
symmetry gate: a vision inspection must inventory corresponding elements from
the visible centerline outward and provide one structured pair row for every
position.

For a conventional bilateral necklace, all corresponding rows must agree on
motif order, mirrored orientation, spacing, scale, metal treatment, pave
coverage, gemstone treatment, and connection type. Missing evidence fails
closed. Designer-requested asymmetry remains valid only when every visible
difference is explicitly authorized; an identity source may likewise preserve
its visible asymmetry.

`cases.json` records the contract-only status and zero provider calls. It does
not add necklace sources to the frozen founder corpus, whose quality-assigned
slice remains the advisory 58-source ring set. No founder, GIA, or independent
designer review has been run for these fixtures.
