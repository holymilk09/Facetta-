This is an evidence-only live Grok evaluation of founder reference
`image-78.jpg` (`b9c4e35b...`). No project, product asset, approval, or factory
artifact was created.

The broad plate-read scorer returned 100 because it recognized a ring, the
green emerald-cut centre, the octagonal geometry, and three stone groups. The
independent component audit still returned `review_required` with five
factory blockers:

- the visible round-stone halo/surround is not mapped to a distinct canonical
  stone group;
- the gem-bearing shoulder group is not mapped to a distinct canonical stone
  group; and
- the primary setting evidence conflicts (`bezel` in the primary read versus
  `prong` in the blind inventory).

This is the intended distinction: semantic recognition is not sufficient for
factory truth. A designer must correct the exact component mappings and
setting fact, then repeat the blind audit. Until that happens, the draft may be
reviewed but cannot become factory-ready.

The previous run of the same case returned an invalid contradictory mapping.
The v2 harness records independent-audit failures separately from plate-read
failures and retains the draft plus blockers for diagnosis.
